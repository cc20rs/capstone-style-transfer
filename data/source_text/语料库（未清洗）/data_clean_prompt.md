# 文档处理任务说明

## 任务目标
你需要处理一个Word文档格式的文本内容，从中提取指定信息并转化为结构化JSON格式。

## 输入文档特征
1. 文档包含多个章节，每个章节以"一、""二、"等序号开头
2. 每个章节包含多个编号条目，格式为【数字】，如【001】、【002】
3. 每个编号条目包含：
   - 内容标签（如"医院成长环境、家庭成员缺席"）
   - 一个或多个文本段落
   - 引用作品名（如"——余华自传《最初的岁月》"）

## 处理要求
1. **处理范围**：从文档第二页开始处理（跳过第一页）
2. **内容提取**：只提取纯文本段落，去除以下内容：
   - 大标题（如"一、出生与童年"）
   - 章节描述（如"（关于余华出生、家庭来历、童年生活的自述）"）
   - 编号标记（如【001】）
   - 内容标签（如"出生记忆、家庭氛围"）
   - 引用作品名（如"——余华自传《最初的岁月》"）
3. **文本合并**：将每个编号条目下的多个段落合并为一个连续的文本块
4. **字段推断**：根据内容推断以下信息：
   - `stage`：人物所处的人生阶段
   - `location`：事件发生的主要地点类型
   - `event`：事件性质

## 输出格式
为每个编号条目生成一个独立的JSON对象，格式如下：

json
{
  "corpus_id": "yu_hua_001",
  "author": "余华",
  "content": "具体文本内容",
  "stage": "对应阶段",
  "location": "对应地点", 
  "event": "对应事件"
}


## 字段说明
1. **corpus_id**：格式为"作者拼音_三位数字编号"，如余华的第一个条目为"yu_hua_001"
2. **author**：固定为"余华"（根据文档内容确定作者）
3. **content**：提起到的文本内容，段落之间用"\n\n "隔开
4. **stage**：取值严格按照`data\source_text\scene_and_recall.md`的`1. 场景标签设计（正交扁平化）`的限制
5. **location**：取值严格按照`data\source_text\scene_and_recall.md`的`1. 场景标签设计（正交扁平化）`的限制
6. **event**：取值严格按照`data\source_text\scene_and_recall.md`的`1. 场景标签设计（正交扁平化）`的限制


## 处理步骤
1. 识别文档结构，找到所有编号条目（从【001】开始）
2. 为每个编号条目提取文本内容
3. 清理文本，移除格式标记
4. 推断stage、location、event字段
5. 生成完整的JSON对象
